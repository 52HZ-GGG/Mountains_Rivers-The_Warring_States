## 程序接入状态（2026-09-19，GitHub pull 后复核）

> 科技解耦与美术门面改动**已在仓库中**，pull 后无需重做。以下为当前接线说明。

### 架构（科技）

| 模块 | 路径 | 职责 |
|---|---|---|
| TechSystem | `scripts/systems/tech_system.gd` | 研究状态机（互斥/精通/协同/AI） |
| TechEffects | `scripts/autoload/tech_effects.gd` | 效果查询唯一入口 |
| TechUnlockContext | `scripts/autoload/tech_unlock_context.gd` | 解锁条件门面 |
| ArtCatalog | `scripts/ui/art_catalog.gd` | ai_art 路径解析 |
| 校验 | `tools/validate_tech_tree.py` | 当前 0 ERROR（72 科技） |

### 美术路径（经 ArtCatalog）

| 类型 | 优先路径 | API |
|---|---|---|
| 地形（含季节） | `assets/ai_art/terrain/` | `ArtCatalog.terrain_texture(id, season)` |
| 城市图标（50） | `assets/ai_art/cities/` | `ArtCatalog.city_texture(city_id, faction, is_capital)` |
| 面板（含外交/科技/学派/存档） | `assets/ai_art/ui/panels/` | `ArtCatalog.panel_texture(key)` |
| 按钮四态 | `assets/ai_art/ui/buttons/` | `ArtCatalog.button_stylebox(state)` |
| 资源图标 12 | `assets/ai_art/ui/icons/` | `ArtCatalog.icon_texture(key)`（工匠文件名为 `icon_craftsman.png`） |
| 势力旗 | `assets/ai_art/ui/icons/flag_*.png` | `ArtCatalog.faction_flag(fid)` |
| 建筑图标 | `assets/ai_art/ui/icons/building_*.png` | `ArtCatalog.building_icon(building_id)` |
| 单位 idle | `assets/ai_art/units/` | `ArtCatalog.unit_idle_texture` |
| 演示场景 | `scenes/ui/art_demo/art_preview.tscn` | Godot F5 |
