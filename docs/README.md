## 3. 归档区（过程性文件，不再作为日常入口）

原则：**只保留当前阶段可用到的文件；过程稿、过时规范、历史决策一律归档。**

| 目录 | 内容 |
|---|---|
| `归档/策划决策/` | 阶段 0–7 全部决策记录（设计依据溯源用） |
| `归档/过程稿/计划选型/` | 执行计划、技术栈选型、Claude 配置教程 |
| `归档/过程稿/交接快照/` | Agent 交接、Demo 纵向切片 PROMPT、战斗分支功能快照 |
| `归档/过程稿/旧规范/` | 接口文档（阶段 0 冻结稿）、美术策划案（旧版）、单位移动动画指南 |
| `归档/过程稿/程序任务/` | 历史 PROMPT 任务稿 |
| `归档/过程稿/superpowers/` | Superpowers 计划/规格过程稿 |
| `归档/英文协作参考/` | 已有中文正式版的英文镜像 |
| `归档/历史交付/` | 重复副本等历史留档 |

若需回溯「某机制为什么这样定」，优先查 `归档/策划决策/` 与 `机制概览/` 中的决策编号引用。

---

## 4. 维护规则

1. 机制正文只写在 `机制概览/`，以当前可玩规则为准
2. 新文档默认放正式区对应子目录；确认为过程稿后移入 `归档/`
3. 不再维护 `PROMPT-*`、一次性计划、过时选型/配置类文档
4. 目录调整后同步更新本文件与 `CODEMAP.md`
