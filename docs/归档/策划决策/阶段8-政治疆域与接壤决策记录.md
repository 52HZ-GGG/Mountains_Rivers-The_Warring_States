## 背景：三套边界概念不统一

| 概念 | 旧定义 | 问题 |
|:---|:---|:---|
| 政治疆域格 | Voronoi 最近城 + 半径 4~8 | 忽略地形，与外交脱节 |
| 外交接壤 | 任意城距 ≤4（静态 cities.json） | 占城后不变；非真实国境 |
| 腐败远城 | 距首都 >8 | 与国境无关，却叫 border |
| 建筑辖区 | 城周 1 格 | 与政治半径命名易混 |

城池辖区（决策 #123）**明确保持**城周 1 格，仅用于建筑放置。

## 关键决策

### 决策 200：三层疆域模型

**选定方案**：

| 层 | 定义 | 用途 |
|:---|:---|:---|
| L0 核心圈 | 城周 1 格环 | 建筑/城墙 |
| L1 实控圈 | 影响力+填洞归属 | 政治图、接壤 |
| L2 缓冲/荒地 | 边境争议与无主 | 中立展示 |

**理由**：建筑玩法需要稳定小辖区；外交与地图需要随征服变化的大疆域；分层避免「半径 8 也能盖房」的荒谬。

**已落地**：文档 §14；代码待 D2。

---

### 决策 201：实控算法 — 影响力填充 + 两段式归属

**选定方案**：

```
city_power = 10 + level×4 + (首都?15:0) + floor(dev/10)
control_radius = 3 + level + (首都?1:0)
influence = city_power × decay(d) × terrain_mul(cell)

Pass1：top1/top2
Pass2：
  清晰：top1≥threshold 且 top1/top2≥1.25
  填洞：低分但邻域 ≥5/6 同属 → 归该势力（迭代 3 轮）
  缓冲：比值不足且双方分值够
  荒地：其余
```

**理由**：
- 地形乘子让山河形成天然国界（mountain 0.35 / river 0.55）
- 填洞避免「国内一堆无色地块」
- 比值 1.25 保留边境锯齿与缓冲带
- 比显式每格归属维护成本低，占城自动重算

**参数默认值**（写入 `big_map_political_control.json`）：

| 键 | 值 |
|:---|:---|
| ownership_threshold | 8 |
| dominance_ratio | 1.25 |
| frontier_min_score | 4 |
| hole_fill_neighbor_count | 5 |
| hole_fill_rounds | 3 |
| pass.owner_multiplier | 1.6 |
| pass.enemy_multiplier | 0.5 |

**已落地**：文档；JSON/代码待 D2。

### 决策 202：接壤 = 实控格共享边

**选定方案**：

```
are_bordering(A,B) = ∃ x,y: owner(x)=A, owner(y)=B 且六角相邻
```

**废弃**：城距 ≤ `diplomacy.border_distance_threshold`(4)。

**理由**：
- 与政治图同一套边界，玩家所见即外交所用
- 占城立刻改变接壤，AI 借口/情报不失真
- 严格相邻（distance=1）国境语义清晰；宽松档仅留数据开关

**衍生**：
- `border_changed(A,B,now_bordering)` 信号
- 新接壤 opinion -5（可配置）
- 边境摩擦：接壤且 opinion<0 时概率给 `border_conflict` 借口

**已落地**：文档；代码待 D3。

### 决策 203：允许飞地

**选定方案**：不禁止飞地。

**理由**：战国疆域本就犬牙交错（魏河东、中山、齐西境据点等）。飞地带来补给、文化渗透、外交借口等玩法，禁止会抹平历史感。

**UI**：飞地照常按归属着色，不特殊标记。

---

### 决策 204：国内中立洞必须填平

**选定方案**：Pass2 填洞（邻域多数归属）。

**理由**：纯 threshold 会在城与城、山后出现「国内无色洞」，观感与逻辑皆错。边界锯齿带保留中立，腹地必须实色。

---

### 决策 205：关隘锁边（后置）

**选定方案**：占关隘方 influence ×1.6，敌方 ×0.5。

**落地阶段**：D4，不进 D2 首版，降低首版复杂度。

**理由**：关隘已是可占领 HP 地形；影响力锁边强化「一夫当关」，但依赖关隘归属运行时数据，可后接。

---

### 决策 206：腐败「远城」与接壤解耦

**选定方案**：腐败仍用距首都 >8；文档改称「远城」，不叫 border。

**理由**：行政偏远 ≠ 国境。并入实控边界会改变腐败数值手感，且语义混淆。

---

### 决策 207：L2 影响圈不做首版可视化

**选定方案**：首版只显示实控 + 缓冲/荒地；L2 半透明影响层后置。

**理由**：避免政治图信息过载；实控已够外交与战略决策。
