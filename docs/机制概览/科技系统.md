## 1. 设计概述

**72 项科技**分 4 大类 × 3 时代，通过资源/金币 + 前置链 + 特殊条件 + 互斥路线解锁。研究完成后永久生效；**效果按势力累加**（玩家 / AI 分轨）。消费端一律经 **TechEffects** 门面查询。

### 1.1 分类与时代（以 `tech_tree.json` 为准）

| 类别 | 早期 | 中期 | 晚期 | 合计 |
|:---|:---:|:---:|:---:|:---:|
| 军事 (military) | 7 | 12 | 12 | **31** |
| 经济 (economy) | 5 | 7 | 4 | **16** |
| 民生 (livelihood) | 4 | 6 | 5 | **15** |
| 建筑 (architecture) | 3 | 4 | 3 | **10** |
| **合计** | **19** | **29** | **24** | **72** |

**5 组政策互斥**（同组只能研究其一）：重农/重商、军功/养士、法治/仁政、远交近攻/合纵连横、书同文/百花齐放。

### 1.2 时代定义

| 时代 | 历史对应 | 金币范围 | 回合（⌈cost_gold/100⌉，无加速） |
|:---|:---|:---:|:---:|
| 早期 | 春秋末-战国初 | 60~120 | 1~2 |
| 中期 | 战国中 | 120~300 | 2~3 |
| 晚期 | 战国末-秦统一 | 250~500 | 3~5 |

> `era_gate_enabled: false`：时代仅作分类标签。

## 2. 架构（强制约定）

| 模块 | 职责 | 谁可依赖 |
|:---|:---|:---|
| **TechSystem** | 研究状态机：进度/前置/互斥/资源门/AI 登记/精通/协同标记/存档 | 研究 UI、存档、事件 `tech_researched`、EventManager 路由 |
| **TechEffects** | 效果门面：势力桶 + 学派 runtime；**消费端唯一查询入口** | 战斗/城防/经营/外交/灾害/演武 |
| **TechUnlockContext** | 解锁条件校验门面 | 仅 TechSystem |
| **tech_unlock_bindings.gd** | 组合根：City / Diplomacy / Wonder → Context | 仅 TechSystem `_ready` 绑定 |

**约定**：
1. 战斗、城市经营、战略地图、外交结算、灾害等**禁止**调用 TechSystem 的效果接口。  
2. `TechEffects.attack_modifier(fid, "cavalry")` **已包含 all**；`target="all"` 只返回全局项，**不要**再加一次 all。  
3. 新增效果：先改 TechEffects，再接消费端。新增条件：业务系统向 Context 注册 checker，不要在 TechSystem 里直调 City/Diplomacy。

### 2.1 运行时加成层

外部系统通过 `TechEffects.set_runtime_bonus(faction_id, key, value)` 写入，与科技桶相加：
- 学派/法家 `research_speed_bonus` → `research_speed_modifier`
- 学派政策 `trade_bonus` → 贸易收入

### 2.2 信号

| 信号 | 说明 |
|:---|:---|
| `SignalBus.tech_research_started/completed/cancelled/available` | 研究生命周期 |
| `SignalBus.tech_research_event(event_id, tech_id)` | 研究事件触发 |
| `TechEffects.effects_changed(faction_id)` | 效果桶或 runtime 更新（`*`=全部清空） |
| EventManager `event_triggered` / `event_resolved` | 研究事件走正式弹窗；结算路由回 TechSystem |

## 3. 研究机制

### 3.1 回合与速度

```
base_turns = ⌈cost_gold / 100⌉
speed_mod  = max(0.1, 1 + TechEffects.research_speed_modifier(faction))
cost_turns = ⌈base_turns / speed_mod⌉
```

同一时间仅 1 项研究；每回合进度 +1。

### 3.2 解锁与成本

| 门 | 说明 |
|:---|:---|
| 前置 | `prerequisites` |
| 特殊条件 | 经 TechUnlockContext（城控/声望含科技声望/建筑/北境城列表/奇观） |
| 互斥 | `mutual_exclusion_hard_lock`，AI 同样遵守 |
| 资源 | 有 `cost_resources` 扣资源；否则 `cost_gold_fallback` 扣 `cost_gold` |
| 取消 | **退还**已扣资源/金币；不产生科技效果 |

北境长城城市：代郡、云中、雁门、上谷、渔阳、辽西、辽阳（`balance_params.tech.northern_border_cities`）。

### 3.3 AI 研究

- 间隔：`tech.ai_research_interval_turns`（默认 3）直接完成 1 项  
- 排序：互斥过滤 → 解锁条件过滤 → 晚期 > 中期 > 早期，成本降序  
- 效果写入该势力 TechEffects 桶，**不污染玩家桶**  
- AI 不消耗资源（简化）；纸面科技已消除（会走 TechUnlockContext）

### 3.4 协同 / 研究事件 / 知识卡 / 精通

| 机制 | 数据 | 运行时 |
|:---|:---|:---|
| 协同 | `tech_synergies.json`（12 条） | 研究完成后判定并写入 TechEffects；存档恢复 |
| 研究事件 | `tech_events.json`（11 条）+ 科技 `research_events` | 开始研究掷骰；EventManager 弹窗；`resolve_research_event` 扣 cost/gold、改进度与民心 |
| 知识卡 | `knowledge_card` | 研究后 UI 展示典故 |
| 精通 | 科技 `mastery`（10 项） | `mastery_enabled: true`；`upgrade_mastery` 扣金+帛书，增量经 TechEffects；全局等级上限 `mastery_max_global_level_sum`（50） |

## 4. 效果与消费端（节选）

| 效果 | 消费端（经 TechEffects） |
|:---|:---|
| attack / defense | 战略单位战、演武攻击管线（按势力+兵种类别） |
| unlock_unit | 城池可招募兵种 |
| resource_bonus* | 国家产出 |
| city_defense / garrison / wall_durability | 城防、驻军容量、城池最大 HP |
| siege / border_defense | 攻城伤害、长城类北境防御 |
| terrain_traversal / movement | 大地图可达格与天堑 |
| morale / culture / security / stability_penalty | 民心、文化产出、安定度回合 |
| trade_bonus / trade_route_capacity / exchange | 商路收入、上限、交换比例 |
| corruption_reduction / increase | 腐败结算 |
| population_growth / upkeep | 人口增长、军队维护 |
| recruit_cost_reduction(target) | 征兵效率（分类项已含 all） |
| vision_bonus | 外交情报点数 |
| disaster_resist | 灾异惩罚衰减 |
| diplomacy_bonus / opinion_bonus / reputation_bonus | 外交好感/成本/声望与解锁声望 |
| zoc_range / zoc_cost_immunity | 演武 ZOC |
| event_chance_bonus | 随机事件与研究事件概率 |
| research_speed_bonus + 学派 runtime | 研究回合 |
| synergies / mastery 增量 | 研究完成与精通升级后叠加 |
