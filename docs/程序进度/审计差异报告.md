## 四、当前仍开放的差异

按优先级：

| 优先级 | 项 | 说明 | 建议 |
|---|---|---|---|
| P1 | F5 实机手感 | CLI 冒烟不覆盖真实点击 | 策划试玩后反馈调参 |

| P3 | jurisdiction_radius | 未使用 | 等设计 |
| P3 | 音效/动画 | 无 | 资产就绪后接入 |
