## 二、已实现可玩闭环

### 2.1 主路径（大地图战略）

```
城池面板征兵 → 大地图生成部队 → 选中/蓝格可达 → 移动/打单位/攻城 → 占城
     ↑
AI：征兵 + 经济建造；宣战后战略 AI 推进与交战
```

- **生产**：`recruit_unit_from_city` 扣池/人口/资源，并在城市格 `spawn_unit_at_city`
- **移动**：Dijkstra，按 `terrain.move_cost`，骑兵禁山地等
- **战斗**：单位战用 `combat_resolver`；攻城扣城防 HP，归零占领
- **AI**：未宣战不进攻；宣战后残血优先、邻接攻城、向敌推进

### 2.2 经营与回合

- 税率 5 档、建筑产出、季节修正、特产、腐败、维护费
- 人口进度条增长、饥荒、征兵池（池上限×fill_rate + 小数进度 + 全国约束）
- 民心阈值、厌战、首都陷落/恢复、安定度与叛乱
- 固定玩家首回合；同速保持 `active_factions` 原始次序

### 2.3 文化

城市文化字典、扩散、主流判定、不匹配惩罚、倒戈、文化胜利计数。

### 2.4 存档

- 3 手动槽 + 自动槽（玩家回合结束写入）
- 序列化：城市/GameManager/外交/科技/学派/大夫/奇观/事件/战略单位/Demo

### 2.5 教学/测试用演武

独立六角演武场：移动、战斗、攻城、关隘、海军、火攻、ZoC 等，**保留作教学与测试，非主胜利路径**。

### 2.6 Demo

秦开局 → 出征洛邑 → 演武胜利 → 洛邑归秦 → 完成反馈。
