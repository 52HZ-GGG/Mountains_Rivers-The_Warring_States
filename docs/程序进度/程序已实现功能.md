## 四、机制权威与冲突处理

1. **机制细则以 `docs/机制概览/` 各专项文档为准**（如战斗以 `战斗系统.md`）。
2. 总览与专项冲突时，以专项为准；总览应主动同步。
3. `balance_params.json` 与专项文档冲突时，**改 JSON 对齐专项文档**（Schema 字段名只增不改）。
4. 测试期望与专项文档冲突时，**改测试**。
5. 实现与专项文档冲突时，**改实现**。

**夹击/包围（已对齐）**：夹击 -15；包围 -30、4+ 敌占邻格；不叠加；退出恢复。`balance_params.json` 与演武代码已按此执行；旧测试待改。
